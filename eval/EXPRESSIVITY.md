Sampled 20 of the 337 L2a/L2c rows in [THOUSAND-GRADES.tsv](https://github.com/ml-circuits-research/pro-formaliser/blob/f96102d3932865f8d02505c758a2faa23e84ad04/eval/THOUSAND-GRADES.tsv) with Python 3 `random.Random(24703).sample(eligible, 20)`, keeping TSV order before sampling. I checked the utterances and annotations at dataset revision `a85de79de826f983855aa2dafc6de7548978fbff` and the installed knowledge revision `ba7cbcf2ab78b8b99d077e8958013d52618c6d04`. The primary declarations are `w.request/schema.sop`, `w.request/shards/keys.sop`, and the domain schemas under `.cache/knowledge/docs/worlds/`. Reader lookup observations use the installed worlds without model or overlays. The grades describe previously reviewed proposals. This audit examines whether their missing meanings have an existing representation.

The sample includes missed bindings for declared effects, mismatched catalog families, and meanings carried only as descriptions or unread annotations. A schema-valid request, a catalog-licensed key, and a domain operation that honors the meaning are different checks. These rows do not establish a numerical ceiling for the reader.

An explicit label can be preserved on creation and reused as the written selector of the following request. In the pinned schema an earlier request or target is not a valid value for the consumer’s target identity. The executor resolves the previous result from dialogue state. Binding a particular producer within one circuit needs a typed source for the consumer and corresponding execution semantics.

In the bucket-0 training partition, 877 annotated new drawing objects across 39 kinds used “in a row” for an arrangement. Four rows used the same phrase as an open direction value. The previous requirement of unanimous annotations discarded the arrangement reading. This is a reader training failure even though the catalog also contains a family mismatch. The annotation counts refer only to training rows.
