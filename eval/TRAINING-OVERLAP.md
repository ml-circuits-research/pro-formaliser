# Does the reader handle unfamiliar wording?

On the primary sample, 40.8% of requests with little shared wording had a reasonable proposal. On the second sample the figure was 31.4%. A request with different wording can still describe a familiar task. These figures measure similarity of the words only.

The script compares every sampled request against all distinct training utterances outside its normalized-text holdout group. It tokenizes normalized words and numbers, adds start and end boundaries, and measures the fraction of distinct consecutive three-token sequences in common (intersection divided by union). It assigns a band using the largest similarity to any one training utterance. The high-similarity groups are small. Length, subject matter and task complexity can also differ across bands. ## Which part of the formaliser fails?

A separate diagnostic sampled 50 failures and 25 reasonable cases in each split. It compared the role structure of the reference with the structures of the 64 closest training programs, ignoring their particular values. In 90 of 100 failed cases, a nearby training program had the reference structure. In only 13 of those 100 cases did the formaliser itself propose that structure. Even letting the diagnostic select donors using the reference, the existing alignment produced a fully matching assignment of values in only 3 cases. This uses the annotation as a diagnostic target. A matching structure can omit an instruction that the speaker expressed. It is insufficient for a reasonable verdict.

A second diagnostic sampled 30 primary L1/L2 cases with seed 561907. Review found 11 where existing roles and meanings appeared sufficient. We actually parsed all 30 with spaCy 3.8.14 and en_core_web_sm 3.8.0 on CPU, along with four contrast cases. Of the 11 promising cases, only three had every needed attachment in the parse. On “he moves to the right side of man in orange hat”, the parser distinguished the mover from the endpoint but attached the hat to the movement. Both quoted-title controls treated words inside the quotes as clause structure. The parser experiment measured attachments, without awarding new L3/L4 grades. [Parser and feasibility judgments](ATTACHMENT-REVIEW.tsv)

These experiments point to an inference problem: the reader often has examples of the appropriate operation but lacks evidence for which participant owns a property or which text supplies its value. The next comparison uses candidate structures retrieved from the input alone. A surface span can fill a role only with compatible lexical or catalog evidence for that role and an independently supported connection to its owner.

We tried a role-based transfer that let explicitly labelled operands move to a different order, with catalog-checked values, numbers and quoted literals. The raw input nominated its donor programs. Tests covered previously unseen values and a separately declared world. Across 3,000 normal requests, including 1,000 in a previously unused holdout, the extra proposals only re-expressed readings already available. We removed this path. Its common failure was requiring a complete donor program with a known explicit predicate. A close training example may contain two actions, unresolved words, or a correct local relationship inside an otherwise incomplete program. Such a fragment needs its own evidence before it can be reused.

## Reusing a whole clause with its implicit owner

We also tested excerpts from longer training requests without requiring a written target noun. We retained exact clauses with an explicit predicate, a locally closed circuit, compatible catalog keys and matching programs from at least two distinct training utterances. On the primary frozen model this supplied 4,380 candidate excerpts. Only 54 of the 1,000 test inputs contained a full excerpt. We ran those 54 through the reader with this extension. Five proposal sets changed. In most of them the neighbouring clause still had the wrong target or an incomplete instruction. One standalone command, “make the colour bar length medium”, exposed a simpler missing mechanism. The catalog held the property as a compound identifier and the speaker left the chart implicit. We did not include the excerpt index in the reader.

## Does an incomplete request already have the right actions?

At reader `33434b0`, the primary sample had 265 incomplete requests with one action in the reference. On 250 (94%), at least one proposal already had the same action. On only 42 (16%) did a single proposal also have the same target families and modes and the same property keys, phases and operators for that action. Values and identities were ignored. Among the 119 incomplete requests with multiple reference actions, 57 (48%) matched the ordered actions and six (5%) also matched those slot structures. A more permissive check pooled all proposed target and constraint facts with the correct action sequence, ignoring conflicts and extra facts. Zero incomplete requests gained complete coverage of the reference facts by pooling in this way. This check compares literal values, so a valid paraphrase or a different representation can still succeed semantically. The comparisons use all proposals and decode quoted SOP atoms before comparison. Counts depend on the annotations and serve to locate gaps, without changing semantic verdicts. This result prioritizes connecting properties to participants even in single-action requests.

Two follow-up experiments tested ways to recover the missing facts. On 20 incomplete drawing requests with multiple new targets, expanding the combination limit from 12 to 128 raised the proposal count from 1,041 to 4,863 on the revised noun reader. Four requests gained previously missing object types. None of those four gained a faithful whole request, so the production limit stays at 12.

We also learned local left/right token boundaries for open and numeric values using the frozen primary training model. The strict run required the same action, family, target mode, property and value type across at least six distinct training values with four left and two right context tokens. It proposed six pairs across the primary sample and no previously missing correct pair. Shortening the context to two left and one right token while requiring eight distinct training values produced one new wrong pair, reading “go” as a drawn object's action when the speaker wanted to remove a named part. This pilot was excluded from the reader. It tests a local span method with those evidence requirements; it leaves other learning approaches open.

On the preceding primary replay (`42b5a0e`), 40 of 1,000 sets included an out-of-bank class value marked open, including 27 sets already judged reasonable. Removing those candidates outright would leave one request with no proposal and eliminate six reasonable exact matches. Inspection found that some contested encodings carry a real missing relationship or condition, while others combine unrelated facts into the wrong property. The new compound-effect path checks its source values before reuse. A global cleanup needs separate representations for the recoverable meanings.
