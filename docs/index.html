English to SOP Lang with Prolog

pro-formaliser reads English requests into SOP Lang w.request circuits. It combines examples learned from WebMeet with declarative facts loaded from SOP worlds. A separate English spellchecker can run independently or prepare text before formalisation. SWI-Prolog performs symbolic matching and ranking, and Node prepares candidates and verifies resulting circuits with the native SOP world engine.

A circuit can contain a request act and mood, a target, lookup hints for existing objects, constraints, and wires that preserve filler or unread evidence. The result is a ranked interpretation of the utterance. Live entity lookup, tool execution and a generic reasoner are outside this experiment’s implementation.

Quick start

Run from the repository root. Setup installs pinned tooling and knowledge in .cache/ without root access on the documented Ubuntu environment.

tools/setup
export PATH="$PWD/.cache/node/bin:$PATH"
npm test
node bin/spell.mjs --json "Teh diagram"
node bin/formalise.mjs --worlds-only --json "create an object"

The full reproduction recipe includes training, text-only evaluation and sampling independent review cases. Reproduce the experiment · Repository README
