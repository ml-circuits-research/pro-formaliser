From utterance to request graph

  1. Load knowledge. Node reads the pinned SOP snapshot and any runtime overlays. The resulting vocabulary supplies acts, targets, determiners, discourse cues and typed properties. World loader
  2. Learn from annotated rows. The optional model groups exact utterances and abstracts grounded substitutions into typed patterns. It also learns lexical and context statistics for candidate generation. Training code · Slot forms · Reader context model
  3. Prepare evidence. The reader tokenizes while preserving source positions. It indexes patterns by a literal anchor and length bounds, gathers SOP and learned lexical hits, and prepares alignments to examples or annotated clauses. Text inside quoted labels is masked for clause and negation detection. Text formaliser · Example transfer
  4. Rank candidate circuits. A persistent SWI-Prolog worker receives each prepared request over JSON Lines. Its score orders exact examples, typed templates, alignments and lexical assemblies in descending priority. Template variables bind source spans and enforce their lexical type. Learned word associations can score already grounded action hypotheses. Lexical assemblies join a compatible act, target and constraints, with residual evidence recorded as unread. Before the Prolog shortlist, a frame that separates the target from other arguments can favor a target in its grammatical scope. Linguistic frames and ledger Prolog reader · Property rules · Role attachment
  5. Validate and retain alternatives. Node checks generated SOP against the loaded request schema and available acts and checks copied evidence against the source. Prolog returns a shortlist of twelve plus representatives for competing families declared for the same target phrase. Node retains valid circuits with distinct semantic wire signatures in the generator’s candidates array. The pipeline can select a leading proposal. If the caller supplies discussion context, a separate SWI-Prolog estimator ranks those same circuits using schema, live entities and prior turns. Contextual estimator Schema validation · Grounding checks

Composition and request scope

The reader can read independent clauses and combine their request wires, remapping local references and validating the combined circuit. Composition keeps up to twelve combinations and retains distinct whole-text alternatives. A construction with one grounded creation verb and several clearly delimited objects can produce one request per object, each with its own modifiers. Quotation and list boundaries protect literal content. Ambiguous attachment, especially a noun that could be part of a spatial anchor, can still leave the list incomplete. Composition rules

A clearly punctuated scene or inventory can introduce several new objects with an implicit or shared creation verb. Each item is read with its own description and placement. Preposed placement can travel with the object that follows it, and a supported final command can retain its own request. The composed proposal restores the written clause spans and keeps an unresolved scene setting as unread. Scene lists · List and scope regressions

A scene setting can become a separate request before the object list. The training index checks that independent inputs agree on the local request graph and that every value is written in the setting. It also requires an attested predicate-free setting or an attested predicate-free pattern for the same argument roles. The reader keeps the original setting words and offers the unread version as an alternative. Scene setting transfer

Two individually typed property clauses can share an existing target across a sentence boundary. A named target, pronoun or omitted subject constrains the pairing. Two different written names keep separate request wires. An intervening remark can be retained as filler when independent training examples placed it between instructions. The resulting circuit keeps the original wording. Composition and ownership checks

When training supplies an open-text scene heading before several new objects, independently repeated heading and connector evidence can identify the boundary before the first item. This can split a setting from an item list introduced with a clause such as “with.” The setting still needs its own grounding. Scene heading boundaries

Independently supported heading fragments can bind separate properties such as setting, time and weather before the item list. Each fragment must occupy its own source span and fit a compatible contextual target. A noun’s property phrases can also chain locally, including after a placement whose relation and landmark already have their own evidence. Scene heading fragments · Adjacent noun modifiers

Declared scope cues identify questions, polarity, and conditional boundaries. A fronted or trailing present-state condition can add a selector to an existing target when a singular reference points back to that target and its property and value resolve uniquely. A negative guard uses want=no, while the effect retains its own property and value. Different subjects, unsupported conditions and unresolved properties fall outside this construction. Scope analysis · Scalar guards

A postfix count cue followed by a question mark can introduce a count question when the complete preceding noun phrase is grounded. A declared universal cue immediately before an existing target can supply fill=all and retain the written quantifier evidence. A counted universal such as “all three arrows” also records count=3 on that target. The surrounding reading supplies the action and its properties. Set and count rules

Evidence-preserving candidate readings

The reader can attach an adjacent cardinal or ordinal to a uniquely located target. An adjacent adjective can supply a catalog-licensed property when training independently supports the same family and interpretation. That property selects an existing target or constrains a new result according to target mode. An explicit naming cue can bind a written name on a new target through a declared literal role. Nominal numbers · Nominal modifiers · Explicit name attachment

A world can install a nominal anchor, separator and two open span keys with anchor=nominal. After the target and action have grounded, the reader attaches the two written operands to those keys. A quoted operand can contain the separator. Conflicting attachment or competing boundaries can leave the pair unread. Open text pairs · Nominal pair declarations

A follow-up such as “paint it blue” can bind its written pronoun to the single compatible target of an adjacent request. The reader uses declared continuation pronouns and checks number and family before marking the follow-up target as bound. It keeps independent landmark lookups. A preservation request using “there” needs a placement in the preceding request. Scoped reference tests

When a surface has no direct target reading, the noun morphology can resolve a plural to a uniquely supported lemma using the installed English inflection rules. The lemma supplies the licensed target senses and the original plural supplies source evidence. After composition, the qualifier reader checks each request’s uniquely located words for grounded adjectives, quantity and property phrases. Any added fields keep that request’s local references. Noun morphology · Clause qualifier binding

A target noun can recur in its result payload. The quantity reader locates the noun within its owning request and uses separately grounded result evidence to distinguish the payload occurrence. It attaches a cardinal or ordinal only when the target occurrence and qualifier resolve together. Quantifier evidence · Repeated noun regressions

A world can declare which keys identify an existing target and which keys record its region or arrangement. Given a uniquely located definite or quoted selector before an independently grounded change, the reader offers a circuit with the identity key in the selector phase. Installed language cues can also ground a region or arrangement adjacent to a target noun when the declared key admits the value. Identity selectors · Region and arrangement cues

A declared nominal class can supply a catalog value alongside the evidence for a new target. For example, “radar chart” can identify the kind of object and set its type. Native fixed-value frames can also read a property command such as “bring the grid lines back.” The frame supplies the state, and the property words locate a declared backing slot. The reader uses the request vocabulary’s admitted value and retains unresolved quantifiers or context references as unread evidence. Nominal classes · Fixed properties

A world can bind a request property to an ordered scale. The reader uses the scale’s declared steps and English aliases to interpret a supported adjective before a uniquely grounded noun. Existing targets receive selectors and new targets receive results. If the adjective and its determiner also ground a competing degree reading on the same span, each interpretation remains available in a separate candidate. Nominal scales

After composition, the same fixed-value frames can attach a result to an independently scoped follow-up such as “and show the values on it.” The reader matches the declared connector within that request and preserves its written words and existing lookup. When an earlier clause grounds the family, a native property reading can also offer a contextual target for a follow-up whose other reading treats the property words as the target. Clause-local enrichment · Follow-up regressions

Native English alternations can expose a request body or embedded question by removing declared surrounding words. The reader requires grounded body evidence and enough request wires to account for the recognized clause boundaries. It records the original utterance on a single request or keeps each request’s local words in a composed circuit. Request alternations

When a final sentence matches a declared courtesy phrase, the reader also interprets the preceding body. It keeps recognized requests in the body and carries the submitted closing words on a filler wire. Trailing discourse

A changed predicate can reuse an otherwise grounded training example when native declarations support the same verb sense or a shared frame, and the complete remaining clause fits its argument roles. The output keeps the submitted predicate and original payload evidence. Predicate transfer

A property command can combine an independently learned lead with the exact written command body. SWI-Prolog joins agreeing family and action records at a shared token boundary. It also supports a body assembled from a separately grounded effect and its written owner. The assembled circuit goes through the same catalog and evidence checks as other proposals. Property command training · Prolog join

Instance references pair a supported command with an existing target. A declared code prefix can license a target family for a written ID such as n3. A coordinated list retains each written ID and can produce alternatives for compatible families. A numbered noun retains its full written description, and a spatial marker can link it to a separately grounded numbered landmark. Instance references · Code and spatial declarations

Training can learn a narrower request mode for a predicate, act and target family from independently supported annotations. That mode qualifies the matching reading while the underlying act and written predicate remain available. Predicate-mode learning · Measured grades

Whole-body transfer indexes the unchanged request body after accounting for declared boundary politeness, interjections and terminal punctuation. It preserves interrogative intent, rejects examples that carry prior-turn evidence and checks that literal fields stay grounded. The audits track which meanings the reader recovers and where the world contract falls short. Whole-body transfer · Expressivity audit · Measured grades

Reading the pipeline result

FieldMeaning
sourceThe construction that produced the candidate. Common values include example, template, alignment, lexicon and sequence.
supportTraining frequency where supplied. A reading licensed by SOP worlds alone can have zero support.
statusmatched for a matched construction, partial for a lexical or incomplete reading, or unresolved with empty SOP and the original text kept as unread.
alternativesOther valid, distinct readings. candidateCount and multipleInterpretations summarize the set. When context is supplied, estimation explains its ordering.

Use the reader from Node.js

import { createReader } from './src/runtime.mjs';

const reader = createReader();
try {
  const result = await reader.formalise('create an object', { tab: 'drawing' });
  console.log(result.sop, result.alternatives);
} finally {
  await reader.close();
}

Pass a trained model to createReader(model, worlds) to enable examples and learned patterns. The CLI accepts --model FILE and defaults to .cache/model.json. With --batch, supply one JSON object per line with text and optional context and tab. Use createFormaliser(model, worlds) directly for the text-only stage. The default CLI prints its candidate set. Pass --pipeline for a selected circuit with alternatives. Reader API · Formalisation CLI

Argument roles, coordination and preservation

In a request such as “I’ll have the Grow step deleted from this tree,” the affected object comes before the main predicate. A declared English lead identifies the construction, native participial morphology supplies possible verb lemmas, and the catalog licenses the action for the existing target. A declared source can also supply a selector. The reader preserves an unsupported source phrase as unread. Affected-target reader · Affected-object declarations

A multiword property after a noun can transfer when independent training utterances and different nouns support the same family, act, mode, source phrase and value. An explicit naming result can license the same written name in the next spatial request, including lowercase names. The later target remains a written selector for subsequent resolution. Property phrases · Names across clauses

Replacement and other declared argument frames can separate a written target name, a quoted payload and a typed property. A declared coordinate construction binds a pair of numeric values in order, while spatial requests can bind a relation and a separate landmark lookup through world-specific keys. A targetless spatial reference can expose compatible family hypotheses with unresolved entity lookup for the context estimator. Named arguments · Spatial grounding · World declarations

A native creation role can give a named sort an open text field. The role binds the full complement after a written cue such as “labelled” or “called,” even when words in the label also name familiar object types. The parser keeps quotations intact and checks clause boundaries before accepting an unquoted span. Creation role tests

A transformation frame links a native action to an existing owner and a result introduced by a declared marker. The owner comes from a native noun or kind inventory. The result can come from a typed value inventory or a written span with a declared head. Transformation tests

A verb can itself express a property change. Native action and comparison facts can license a bank value or a relative step through a compatible catalog key. Training can also supply an equality when independent object phrases corroborate the same typed result, with conflicting and missing results counted. Prolog checks the predicate scope before the reader attaches the effect to a grounded existing owner. Verb effect tests

Property edits can introduce an existing owner between the property and its new value, as in “set the y axis title on the regional revenue chart to Headcount.” A declared connector pattern, native change predicate and owner noun identify the property’s scope. A world may bind a native owner inventory. A candidate key can accept written content when its backing native slot is an unrestricted string. Independently licensed owner families remain available as alternatives. Owner-bound property edits

Prolog can join two distinct catalog-backed effects on the same described owner, or read an explicitly separated list of written members governed by one native action. Member labels retain their order and wording. A separate qualifier rule attaches written numeric values to declared numeric keys on an existing target. An explicit pronoun can leave compatible target families for contextual lookup. Coordinated effects · Member lists · Numeric qualifiers

A declared sequence of argument slots can combine catalog values with written spans. Prolog can match an explicit owner at its declared position within that sequence, such as a chart kind before or after its measure. The reader requires a unique ordered binding. A declared trailing boundary lets it preserve an additional unbound phrase as unread. Argument matching · Sequence declarations

An anchorless movement can express a direction without a landmark. Native directional frames and compatible place senses license the predicate. The reader grounds an existing owner or unresolved pronoun and attaches the categorical direction. A declared qualitative distance key can carry written degrees such as “a touch.” The phrase stays unread when a family supplies only a numeric offset key. Directional result tests

A bare indefinite nominal can license a creation reading when the complete phrase supports a new object and its local qualifiers. “A tiny cat behind the big boat” can create the cat with its stated size and a separate landmark. Questions, conditional clauses and nominal statements with their own predicate do not supply this creation pattern. Implicit creation tests

A world can declare an ordered compound reference such as “Start-Finish arrow” through two open span keys on one target family. A native noun and an existing-target action license the family. The reader attaches both written labels as selectors and keeps the target lookup. It also recognizes a complete initial noun phrase followed by a local action and object pronoun, as in “Start-Finish arrow, pick it.” Compound references

A spatial relation can bind an entire definite landmark such as “the damp gravel road” when its terminal noun is licensed by the target’s world. The reader keeps the primary target, attaches the written landmark to its own selector and lookup, and preserves the following aside as unread. Exact region phrases and competing spatial roles use their own readings. Landmark attachment tests

Declared page regions combine spatial phrases with catalog values, including corner names from native layout slots. When the complete phrase belongs to one grounded target, a region reading can replace the matching landmark relation and its lookup. A corner or edge of a named object keeps its object-relative reading. A leading region followed by a comma can qualify the single target of that local request. Region declarations · Region ownership tests

A declared spatial surface can retain a distinction such as immediate adjacency when both the base and specific relations belong to the target’s catalog. The reader can also bind separate written names on each side of a licensed spatial marker. A lowercase bare name needs a single content word in that role, while a complex name can be quoted. Named spatial arguments

Native frames can supply a spatial alias when a fixed relation and at least two declared prepositions agree at the same place argument. The alias supplies that relation while the submitted phrase remains the source evidence. Spatial alias compilation

The reader learns preservation patterns from requests with a grounded target and an explicit preservation property. Compatible stative verb senses can extend an attested construction. A domain may declare a custom preservation key and restrict its values through its catalog. Current training and world knowledge leave some preservation phrases unresolved. Domain bindings

Native English frames also contribute before the Prolog candidate limit and during lexical ranking. The word ledger, grammatical arguments and semantic wire comparison address different questions. Language knowledge · Failure diagnosis

The spatial learner records a landmark phrase only after two distinct object sorts witness its use with the relation and anchor slots of an installed catalog. Multiword relation phrases also require a compatible native meaning. Learned records are optional in saved models. At inference, independent subjects can each have a lookup for the same written landmark. Competing bindings for one subject remain separate proposals. Spatial learner and assembler
