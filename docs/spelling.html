Independent English spellchecker

The spellchecker operates independently of the formaliser. It reads text from the command line or stdin, uses the English dictionary and SOP vocabulary, and enumerates replacements for eligible tokens. Spelling CLI · Dictionaries and licenses

node bin/spell.mjs --json "Teh diagram"
node bin/formalise.mjs --tab drawing --spell --json "make teh house blue"

Generate and rank a correction

The edit model generates one insertion, deletion, substitution or adjacent swap. Candidate scores combine corpus frequency with edit weights. Swaps and doubled-letter edits receive a higher prior. Optional context uses adjacent words from the original text and training-only pair counts to adjust lexical evidence for unknown words. The extended model uses local phrase counts and token frequency to protect plausible unknown words. It can also correct an eligible dictionary word when the neighboring phrase strongly favors a one-edit alternative. A 3× lead over the next candidate is required for an automatic replacement when a runner-up exists. Prolog candidates · Spelling API

The JSON response provides the revised text, corrections and ambiguities. Ranges use UTF-16 start and exclusive end offsets into the original input. Candidate spellings preserve initial capitalization. With --spell --json, formalisation returns the original input, spelling details, and proposals from both the original and corrected readings. A shared circuit appears once and records both readings. spellingReading identifies the input used for its evidence. With --evidence, tokens and spans also carry offsets into the original input. With discussion context or a tab, the reader ranks the combined proposals using each proposal’s own evidence.

Training and evaluation

node tools/train-spelling.mjs builds the optional context model from pinned WebMeet training rows, including word, pair and triple counts. The training pass also protects words corroborated by annotations. The evaluation measures recovery from deterministic one-edit injections, including a separate set that changes a word into another dictionary word. The independent audit judges edits made to unmodified utterances. Without the extended model, dictionary words pass through unchanged. Learned protection and caller-provided protected words also preserve legitimate spellings. The speller can also restore a missing space between two dictionary words. It requires a previously unseen lowercase token, an attested inner word pair, and corroboration from an adjacent three-word phrase. An isolated token or a previously attested compound keeps its spelling under this rule. Context training · Spelling results

The optional context model records a verb and its next word when distinct annotated clauses corroborate that pair. After a catalogued conjunction, this evidence can protect a dictionary verb from substitution by a common preposition. Spelling controls

Cu toate modulele SOP experimentale încărcate, reunirea propunerilor obținute din textul original și din textul corectat a crescut acoperirea de la 52,1 % la 53,5 %. Pe cele 1.000 de cereri, corectarea a adus 14 interpretări complete suplimentare și a îmbunătățit patru interpretări care au rămas incomplete. Fiecare cerere intră o singură dată în calcul.
