# Property visibility

The optional declarations connect an on/off construction to an existing property's catalog. They apply to gridlines, the chart legend, error bars, the colour bar, trend lines and any compatible property with a declared label. The operation uses the property's existing show/hide value bank.

“Switch the gridlines off” grounds the property in `key_words="gridlines"` and the result value in `words="off"`. “Ditch the legend” grounds the result in “Ditch”. Ambiguous “on or off” leaves the choice unresolved.
