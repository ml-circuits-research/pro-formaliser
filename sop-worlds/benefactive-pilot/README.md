# Written beneficiary for a creation request

Load this pilot together with the optional `w.relational` schema. It adds a beneficiary to a grounded creation whose written construction is licensed by the language world's dative alternation. The recipient stays linked to the request with its exact words and a pronoun or name category. The reading leaves identity resolution to the contextual layer. A recognisable name that is also a time expression, such as “May” in “for May”, stays ambiguous.

For a worlds-only check, run from the repository root after setup.

```sh
SOP_WORLDS=sop-worlds node bin/formalise.mjs --worlds-only --json --evidence \
  'Build me a bar chart of monthly totals of orders'
```
