# Optional expressions on drawn figures

The pilot appends five values to the closed drawn.expression catalog from the pinned knowledge snapshot. In the frozen bucket-0 training model, distinct examples used curious (139), tired (60), excited (44), proud (20) and upset (19) as expression values. Four also have named entries in k.feelings with facial features. The evidence for upset here comes from the request corpus.

The accompanying nominal pattern reads the complete authored phrase, for example “with an upset face”, after a grounded new target. The same pattern uses every compatible value installed in that catalog. It preserves the phrase in the evidence and allows a subsequent placement to remain attached to the figure. Without an installed value, that pattern cannot bind it.

To run with the frozen model, set `SOP_WORLDS=sop-worlds/expression-pilot`. The same-ID catalog row retains the fields and values of snapshot ba7cbcf2. To integrate with a newer snapshot, append only the missing values to the live row. A consumer needs to verify support for the new expressions on the intended figures; this test measures request interpretation.
